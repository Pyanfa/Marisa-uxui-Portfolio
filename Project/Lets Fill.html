Project Title

Let's Fill

A mobile web application designed for dental students to practice cavity restoration techniques within a simulated environment. Because tooth filling involves multi-step, highly intricate procedures, the platform provides guided step-by-step practice, immediate feedback, and self-assessment features to prepare students for real-world clinical practice.

Usability Testing

Dental Building, Chiang Mai University

Revealed key usability challenges

Unclear Solution

Users were often uncertain about the next action required on screen.

Added contextual hints to guide users smoothly to the next step and streamline their training session.

Need for Detailed Performance Feedback

Users needed detailed feedback to assess their performance accurately.

Enhanced the result display to provide clear, granular performance insights.

Specific testing procedures and user data are omitted due to NDA restrictions.

Key Design Decision

Reduce Cognitive Load

Users already struggle to comprehend intricate dental procedures.

Reduced UI cognitive load to allow users to focus fully on the learning content.

Used distinct colors to categorize button functions and maintained consistent layout positioning across pages.

Performance Feedback

Since practice is the primary goal, users require detailed performance feedback to measure their skill level and track overall progress.

Helped users review and evaluate their training results with greater clarity.

Added comprehensive level-by-level performance summaries, detailing scores, step-by-step completion times, and total attempts.

Answer Feedback

While students must practice zero-tolerance procedures, repetitive learning without precise feedback or with overly abrupt feedback leads to the retention of incorrect habits.

Provides immediate answer feedback to reinforce learning and improve retention.

Displays immediate response feedback with a 2-second delay before advancing or retrying, giving users sufficient time to process results.

Hands on Practice

The project aims to ensure that web-based simulation practice successfully transfers skills to real-world clinical practice.

Designed a simulated environment that enables hands-on practice with dental instruments and step-by-step cavity restoration procedures.

Designed tool interactions that mirror real-world operations through natural touch, stylus, and click gestures.
